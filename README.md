A tiny program that writes the funniest error message a kitchen toaster would show its owner — one line, at most 120 characters. Built by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset), validates it against the competition gate (one line, 1–120 characters, not only whitespace), reads it back to confirm it matches, and exits 0.
